# Music library

Drop royalty-free tracks here (`.mp3`, `.m4a`, `.wav`, `.ogg`). They are served at
`/music/<file>` and listed by `GET /api/tracks`, so the studio's song list picks
them up automatically. A few demo tracks are included so the mixer works offline.

Suggested sources for licensed, free-to-use music:

- **Free Music Archive** — https://freemusicarchive.org (filter: CC / commercial use)
- **Pixabay Music** — https://pixabay.com/music
- **YouTube Audio Library** — https://studio.youtube.com (Audio Library tab)
- **Uppbeat / Bensound** — free tier with attribution

Keep the licence file next to each track (e.g. `track-name.LICENSE.txt`) so every
export can be traced back to its terms.
